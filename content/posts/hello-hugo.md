欢迎来到这个博客。

这是第一篇文章，纯文字，没有代码块也没有图片，主要用来确认几件事：

- 中文标题、中文标签、中文分类能不能正常显示；
- 正文里的**加粗**、*斜体*、[链接](https://gohugo.io/)、`行内代码` 这些基础 Markdown 语法渲染是否正常；
- 长段落在手机宽度下会不会出现横向滚动。

## 这个博客是怎么来的

站点由 [Hugo](https://gohugo.io/) 生成，主题用的是 [PaperMod](https://github.com/adityatelange/hugo-PaperMod)，托管在 GitHub Pages 上，每次往 `content/posts/` 目录里新增一篇 Markdown 文件并推送到主分支，GitHub Actions 就会自动构建并发布，几十秒后就能在线上看到。
